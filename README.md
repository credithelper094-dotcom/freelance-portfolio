# Freelance Portfolio\n\nFreelance product builder focused on useful interfaces, client systems, and B2B workflows.\n\n> Один проект в подборке — реальный репозиторий. Три остальных — демонстрационные концепт-кейсы, созданные для визуализации направления портфолио.\n\n## Проекты\n\n### 01 — B2B Marketplace Android\nПолноценное переписывание B2B-приложения: современный Android-стек, оптимизация производительности, offline-режим и очередь заказов.\n[Открыть репозиторий](https://github.com/credithelper094-dotcom/b2b-marketplace-android)\n\n### 02 — FreelancerFlow · концепт\nМини-CRM для фрилансеров: лиды, статусы проектов, брифы, дедлайны и история коммуникации в одном рабочем пространстве.\n\n### 03 — QuickBrief · концепт\nУмная форма брифа, которая превращает хаотичное сообщение клиента в структурированную задачу с бюджетом, сроками и следующим шагом.\n\n### 04 — Atelier Landing · концепт\nЛендинг креативной студии с сильным первым экраном, витриной услуг и коротким маршрутом от интереса до заявки.\n\n## Стек\n\nHTML · CSS · JavaScript · Android · Product thinking · UX writing\n\n## Локальный просмотр\n\nОткройте `index.html` в браузере или включите GitHub Pages в настройках репозитория.\n
